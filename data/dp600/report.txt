q175: Key (try_cast for ItemName) matches the exam's intended answer, but technically TRY_CAST(x AS varchar(20)) does NOT return NULL for strings longer than 20 characters: explicit conversions between character types silently truncate; TRY_CAST only returns NULL when the conversion fails (e.g. invalid format). A true NULL-if-too-long needs CASE WHEN LEN(item_name) > 20 THEN NULL ELSE item_name END. None of the offered options does that, so try_cast is the best available answer. convert style 7 (Mon dd, yy) is correct.
